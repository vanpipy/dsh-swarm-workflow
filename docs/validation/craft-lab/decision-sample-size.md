# The comparison runs one arm per condition

Date: 2026-11-14. Asked by the Lead, answered by the user.

## The question

The craft arm and the control arm are one lane each. A single pair can show a
difference but cannot prove one: two lanes from the same model family may
differ by chance, and with one sample there is no way to tell a real effect
from a lucky draw.

## The options

1. One arm per condition, as it stands.
2. Three arms per condition — three craft lanes and three control lanes — so
   the comparison rests on more than one sample.

## The decision

Option 1. The user answered "Accept the indicative result".

## What it means for the report

The acceptance report states plainly that the difference between the arms is
indicative, not conclusive, and names what a conclusive test would need: more
than one lane per condition, with the conditions identical apart from the
craft guidance.

## A limit this decision does not cover

The control arm's own report disclosed that its session carried the skill
catalog the plugin registers for every agent, and that the lane loaded the
craft skills before it read the specification, while deriving nothing in the
implementation or the report from them. The comparison is therefore between
*two briefs*, not between two environments: the plugin registers the craft for
every agent, so a brief alone cannot isolate it. A clean control would need a
session where the craft skills are not registered at all.
